# LabelPlus 排版 txt 格式规范

本文描述 lp2psd 所解析的 LabelPlus 导出排版文件格式,解析实现在 `src/layout.cpp:63`(`parse_layout`)。样例见 `testfile/text1.txt`。

## 总体结构

一个 txt 由三部分组成:

```
① 头部:分组名映射区(第一个图片块之前的行)
② 一到多个图片块:每块 = 图片块起始行 + 若干条目
③ 条目:条目头行 + 若干文本行
```

空行(全空白)在任何位置都被跳过;每行先做首尾空白 trim。

## ① 头部:分组名映射

头部区建立"分组号 → PSD 图层组名"的映射。两种写法都被接受:

**写法 A:LabelPlus 样例注释式**(每行一个,带 `---` 与"对应"注释)

```
框内 --- (psd 分组名称 对应 1)
框外 --- (psd 分组名称 对应 2)
```

规则(layout.cpp:109-131):行内出现 `---`(且不在行首)时,`---` 之前的部分为组名;`对应` 之后出现的第一个整数为组号(不存在"对应"则按出现顺序从 1 递增)。同组号重复出现时后者覆盖前者。

**写法 B:真实导出式**(纯行列表)

```
1,0
-
框内
框外
-
Default Comment
You can edit me
```

规则(layout.cpp:136-172),按顺序判断:

| 行 | 处理 |
|---|---|
| `数字,数字`(如 `1,0`) | 文档/页 id 头,跳过 |
| `-`、`=`、`#` 开头 | 分隔行或注释,跳过 |
| `Default Comment`、`You can edit me` 开头(忽略大小写) | 已知注释行,跳过 |
| 其它 | 依次分配组号 1、2、3…(出现顺序即组号) |

写法 A 与 B 可混用;组号相同后写覆盖先写。若某组号在条目中被引用但没有名字,生成 PSD 时组名回落为 `Group N`(main.cpp:112)。

## ② 图片块起始行

```
>>>>>>>>[01.jpg]<<<<<<<<
```

识别条件:trim 后以 `>>>>>>>>[` 开头(layout.cpp:83,兼容 9 个 `>` 的变体)。方括号内为图片文件名,相对 **txt 所在目录**解析(可带子目录路径)。之后直到下一个图片块起始行之间的所有条目都属于该图片。

每个图片块输出一个 PSD:`<输出目录>/<图片名去扩展名>.psd`。

## ③ 条目

**条目头行**:

```
----------------[1]----------------[0.203,0.043,2]
```

识别条件:行首为 `-` 且能被 `parse_entry_line`(layout.cpp:25)解析。格式:

- 第一个 `[N]`:条目序号(纯数字;仅用于展示,PSD 里不使用)。
- 第二个 `[x,y,group]`:
  - `x`、`y`:文本锚点在**图片宽高上的归一化坐标**,范围 0..1。生成时乘以图片像素宽高得到文档像素坐标(图层左上角)。
  - `group`:分组号。`0` 或负数表示不属于任何分组(图层直接放在 PSD 顶层)。
- 条目头行中的 `---` 破折线数量、空格不影响解析。

**文本行**:条目头行之后、下一个条目头/图片块/文件尾之前的所有非空行,依序作为该条目的文本,行与行之间以 `\n` 连接写入图层。

**转义换行**:单条文本行内可以写字面 `\r` 或 `\n`(反斜杠 + 字符),会被展开成真实的换行(main.cpp:124 `split_escaped_lines`)。例如 `第一行\n第二行` 生成两行文本。

## 编码

`read_text_file`(src/textcodec.hpp:42)按以下顺序探测:

1. UTF-8 BOM(`EF BB BF`)
2. UTF-16LE BOM(`FF FE`)
3. UTF-16BE BOM(`FE FF`)
4. 无 BOM:先做严格 UTF-8 校验,通过则按 UTF-8
5. 校验失败:按系统 ANSI 代码页解码(中文 Windows 即 GBK)

## 一个完整样例

```
1,0
-
框内
框外
-

>>>>>>>>[01.jpg]<<<<<<<<
----------------[1]----------------[0.203,0.043,2]
Letter.7 红叶

----------------[2]----------------[0.649,0.128,1]
我总把周遭看遍
随人潮冷暖周旋

>>>>>>>>[02.jpg]<<<<<<<<
----------------[1]----------------[0.959,0.026,0]
无分组,放顶层
```

- `01.jpg` 得到两个分组:组 2 "框外"(条目 1)、组 1 "框内"(条目 2);PS 中 "框内" 组在 "框外" 之上(分组映射先出现的组号在上)。
- `02.jpg` 的条目 1 组号为 0,不进组。

## 解析失败情形

- 找不到任何图片块起始行 → `parse_layout` 返回 false,报 "no image blocks found in text file"(layout.cpp:195-197)。
- 文件打不开 → "cannot open text file"。
- 条目头行格式不符(如第二个括号缺 3 个数)时**不会**报错——该行回落为普通文本行,追加到上一个条目(layout.cpp:192)。调试"文本莫名多了一行"时先检查条目头行拼写。
